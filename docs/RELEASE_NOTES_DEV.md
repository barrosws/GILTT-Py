# Development release notes — QA-057 candidate

GILTT-Py remains a development package (`0.0.0.dev1`). These notes describe the QA-057 candidate checkpoint and are not public release notes.

The principal operational addition is a single governed command for replaying the QA suite from a frozen project root. The command is backed by a TOML plan, exact test-file coverage checks, expected test counts, frozen thread/hash controls and optional machine-readable evidence output.

The checkpoint also adds an installation quickstart, reproducibility instructions, a development changelog and automated code-coverage evidence for the new operational layer. Full-package coverage remains HOLD. Coverage is used only as engineering observability; no numerical coverage percentage extends the scientific claim envelope.

Still unresolved and therefore not promoted: manuscript table/figure reproduction, all final scientific-run configs, complete data/source redistribution-rights provenance, software authorship/ORCIDs, software license, DOI, public semantic version/date, cross-platform CI completion and Zenodo deposition.
