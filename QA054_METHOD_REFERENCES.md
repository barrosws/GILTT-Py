# QA-054 Method references

- Citation File Format (CFF): target format `cff-version: 1.2.0`; `CITATION.cff` is human- and machine-readable citation metadata for software.
- Python Packaging User Guide / PEP 639: modern package licensing uses an SPDX-compatible `license` string and a separate `license-files` list.
- PyPA backend-support table: setuptools 77.0.3 introduced support for the current PEP 639 `pyproject.toml` license syntax.
- Core Metadata licensing contract: PEP 639 maps the SPDX expression and included license files to modern distribution metadata.
- GILTT-Py Reproducibility & Zenodo Protocol v0.1: software license must be explicitly selected before public release; data redistribution rights are assessed dataset-by-dataset; citation metadata and authorship must be reviewed before Zenodo deposition.
